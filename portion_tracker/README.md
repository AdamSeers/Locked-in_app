# Portion Tracker

A simple Flutter app for tracking your daily food portions.

## How it works

- **Today** tab — each food category shown as a card in a 2-column grid,
  with how many portions are left today. Tap a card to log one portion
  (reduces the remaining count; the card greys out once you hit 0).
  Long-press a card to see more info about that food group, in a sheet
  that slides up from the bottom.
- **Full List** tab — every portion for the day, grouped by food type, in
  order. Logging a portion on the Today tab greys out the earliest
  not-yet-done entry of that type here.
- Everything resets automatically at **3:00 AM**, whether or not the app
  is open when it happens.

## Setup

This only includes `lib/`, `pubspec.yaml`, and `analysis_options.yaml` —
the Dart/Flutter source. It leaves out the generated Android/iOS platform
folders on purpose, since those should be generated by your own Flutter
SDK (they're tied to whatever Flutter/Gradle version you have installed).

1. Make sure the Flutter SDK is installed (`flutter doctor`).
2. Scaffold a fresh project, then copy these files in:
   ```
   flutter create portion_tracker
   cd portion_tracker
   ```
   Replace the generated `lib/` folder and `pubspec.yaml` with the ones
   here, and add `analysis_options.yaml`. Delete the generated
   `test/widget_test.dart` — it tests the default counter app, not this
   one.
3. Get dependencies: `flutter pub get`
4. Run it: `flutter run` (with an emulator running or a device plugged in)

## Customizing

- Food types, emoji, colors, daily goals, and info text all live in
  `lib/data/food_types_data.dart`. The 6 categories and portion counts in
  there are just reasonable placeholders — edit the list to match what
  you actually want to track.
- The reset hour lives as `_resetHour` at the top of
  `lib/providers/portion_provider.dart`.
